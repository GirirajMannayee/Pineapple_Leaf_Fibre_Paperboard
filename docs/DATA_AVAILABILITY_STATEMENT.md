# Data availability statement (ready to paste)

> The datasets, analysis code, figures and Excel workbook supporting this study are openly available in the repository **PALF-FSM-Paperboard-Datapack** at **[DOI / URL – insert after archiving, e.g. Zenodo]** (version 1.0.0). The repository contains tidy CSV files for every experiment (pulp, sheets, mucilage, turmeric, formulations, 30-run response-surface design with 90 replicate records, package performance, storage trial, specimens and coating DOE), a data dictionary, Python scripts that regenerate all models, optimisations, statistics and figures, and a reproducibility report comparing 462 recomputed values with those in the manuscript. Model-derived values (response-surface predictions, optimum and prediction intervals) are labelled as such and are not experimental measurements.
